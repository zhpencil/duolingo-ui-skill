# Duolingo UI — Token 全表

这份表回答一个问题：**页面上的每个数值从哪来、为什么是这个数、什么时候可以换。** 所有值都从 Figma 的 `Duolingo Design System` 节点里读出，再用另外两个文件交叉核对；`assets/duolingo.css` 里的 CSS 变量和这里一一对应。单位全部是 px，不做视口缩放。

## 1. 颜色

### 1.2 中性色

中性色负责“让彩色跳出来”，它们不是灰色的随便几档，而是有严格分工：

| 变量 | 色值 | 用途 |
|---|---|---|
| `--duo-eel` | `#4b4b4b` | 正文、按钮深色文字、深色 Toast 底 |
| `--duo-wolf` | `#777777` | 次要文字、章节说明、对话框正文 |
| `--duo-hare` | `#afafaf` | 三级文字、计数器图标、关闭按钮、占位符 |
| `--duo-swan` | `#e5e5e5` | 2px 描边、进度轨道、禁用面、灰节点 |
| `--duo-polar` | `#f7f7f7` | 页面洗底、吉祥物块底、展示页底 |
| `--duo-snow` | `#ffffff` | 所有内容面 |
| `--duo-scrim` | `rgba(0,0,0,.5)` | 弹层遮罩；不是模糊，是纯 50% 黑 |

语义别名：`--duo-text` = eel，`--duo-text-2` = wolf，`--duo-text-3` = hare，`--duo-line` = swan，`--duo-blue` = macaw-500，`--duo-green` = feather-500，`--duo-purple` = beetle-500。

### 1.3 配色规则

- **面 / 边必须成对。** 绿色面只能配 `#478700`，蓝色面只能配 `#1899d6`，紫色面只能配 `#a568cc`，金色面只能配 `#e6a000`，红色面只能配 `#e53b3b`。不要用一个颜色的边去配另一个颜色的面。
- **白字只放在 500 面或深色底上。** 金色是例外：金面必须用 `#cd7900` 深字，白字对比不足。
- **淡色洗底只配同族的 700 文字。** `#d6ffb8` 配 `#58a700`，`#ffdfe0` 配 `#d33131`，`#ddf4ff` 配 `#1cb0f6`。不要用 eel 黑字压在淡绿上，会显得脏。
- **纯黑只出现在两个地方**：home indicator（`#000`）和遮罩。文字不要用 `#000`，连标题也不用。
- **不要新增相邻色。** 需要“更浅的绿”时用 `feather-100`，不要自己调 `#e8ffe0`；需要“更深的紫”时用 `beetle-600`，不要再压暗。

### 1.4 推导规则（原稿没有的颜色）

如果要给一个没有明确定义的状态取色，按下面的比例推，不要凭眼睛：

- **洗底**：把 500 色与白色按 1:4 混合（约 20% 色 + 80% 白），例如 `#1cb0f6` → `#d1ebf7`。
- **底边**：把 500 色压暗约 20–25% 明度，例如 `#58cc02` → `#478700`。
- **按下**：底边再压暗 5%，或直接使用已有的 600 / 700 档。
- **禁用**：面、边、文字全部退到 `swan` / `hare`，不要只降透明度。

## 2. 字体

### 2.1 字族

```css
--duo-font: "DIN 2014 Rounded VF", "DIN Next Rounded", "din-round",
  "Duo Rounded", "Nunito", ui-rounded, "Segoe UI Rounded", system-ui, sans-serif;
--duo-font-web: "Instrument Sans", "Inter", "Duo Rounded", "Nunito", system-ui, sans-serif;
```

`Duo Rounded` 是 `@font-face` 里的别名，指向 `fonts/nunito-latin.woff2`，可变字重 200–900。它只是 DIN 2014 Rounded 的替身：DIN 的字碗更方、字宽更均匀，Nunito 更圆、更窄。**排版时以“控件不溢出”为准，不要追求和 Figma 逐字对齐。** 如果用户拥有 DIN 授权，把字体文件放到 `fonts/` 并在 `@font-face` 里换成 DIN，其它 token 不需要动。

### 2.2 字号表

| 名称 | 字号 | 字重 | 字距 | 行高 | 典型用途 |
|---|---|---|---|---|---|
| Display | 96px | 800 | -2px | 1 | 连胜数字、庆祝大数字 |
| H1 | 32px | 800 | -0.5px | 1.15 | 课程完成标题 |
| H2 | 26px | 800 | -0.52px | 1.2 | 屏幕标题、资料名、小节标题 |
| H3 | 22px | 800 | -0.44px | 1.2 | 分区标题、对话框标题、资料统计值 |
| H4 | 21px | 800 | -0.105px | 1.1 | 卡片标题、任务标题、章节头、好友卡 |
| Body large | 20px | 400 | +0.6px | 1.2 | 题目、词卡、课程名、选项行 |
| Body | 16px | 400 | -0.16px | 1.2 | 默认正文、按钮、计数 |
| Small | 14px | 400 | 0 | 1.2 | Web 列表副标题、徽章 |
| Micro | 12px | 400 | 0 | 1.2 | 微型标签 |

补充：按钮是 **16/800 大写 +0.8px**；eyebrow 是 **15/800 大写 +0.2px**；对话框正文 **18/400 #777**，行高 1.4；词卡 **20/400 +0.6**；任务标题 **21/800**。正文字号不要低于 16px（移动端），14px 只用于 Web 的次级信息。

### 2.3 字重与字排

- 800 是“Duolingo 重”，用于所有标题、按钮、数字、名字。700 只用于设置行标题和上屏的单词。400 用于正文、词卡、说明。
- **大字号收紧、小字号放松**：26px 以上用负字距，20px 用正字距，16px 回到轻微负值。不要把全局 `letter-spacing` 设成 0，也不要把所有标题都设成 `-1px`。
- 大写只用于按钮、eyebrow、分区小标题（如 `SECTION 2, UNIT 10`）。正文、课程名、句子一律保持原大小写。
- 行高偏紧：标题 1.1–1.2，正文 1.2。只有大段说明才用 1.4–1.45。Duolingo 不靠行距撑开，而靠分组和留白。

## 3. 圆角

| 变量 | 值 | 用途 |
|---|---|---|
| `--duo-r-xs` | 8px | 图标按钮、导航点击块 |
| `--duo-r-sm` | 10px | 小按钮、完成 / 特殊任务卡、底部 sheet 的按钮 |
| `--duo-r` | 13px | 主按钮、词卡、课程行、选择行、卡片、Toast、输入框（12px 近似） |
| `--duo-r-lg` | 16px | 大按钮、气泡、资料卡、对话框、卡片大版 |
| `--duo-r-xl` | 20px | 底部弹层顶部圆角 |
| `--duo-r-pill` | 999px | 进度条、开关、徽章、头像、好友圆点、grabber |

规则：**按钮不圆成胶囊**，主按钮 13px、大按钮 16px、小按钮 10px。只有进度条、开关、头像、徽章、Toast 里的数字胶囊可以用 full pill。

## 4. 描边与实心底边

### 4.1 描边

- 主轮廓 **2px `#e5e5e5`**：卡片、词卡、课程行、所选行、输入框、分段头、底部导航选中块的内描边、Toast 的边界（用阴影代替）。
- 1px 只出现在底部导航的顶部分隔线，以及个别展示板的细分隔。**不要把卡片描边改成 1px**，那会立刻失去厚度。
- 深色描边只用于彩色块上的分隔：章节头的按钮列是 `2px #a568cc`，进度条的轨道没有深色描边。
- 焦点环：**3px `#1cb0f6`，外扩 3px**。键盘可见时才出现，用 `:focus-visible`。

### 4.2 按钮底边

| 尺寸 | 面高 | 底边 | 圆角 | 按下位移 |
|---|---|---|---|---|
| 默认 | 48px | 5px | 13px | 5px |
| 大 | 52px | 5px | 16px | 5px |
| 小 | 38px | 3px | 10px | 3px |
| 次按钮 | 48px | 5px（`#e5e5e5`）+ 2px 边框 | 13px | 5px |

底边的实现是 `box-shadow: 0 Npx 0 color`，不是 border-bottom，也不是伪元素。按下时 `transform: translateY(Npx)` 并把阴影收成 `0 0 0`。这样按钮的**外框高度不变**，周围布局不会跳。

### 4.3 卡片“纸边”

`box-shadow: 0 2px 0 var(--duo-line)`。这是一条 2px 的实心影子，跟 2px 描边一起构成“厚纸片”。课程行和选择行用 3px，因为它们的面更高。

## 7. 间距

Duolingo 不用 4/8 的严格网格，而是**跟着内容高度走**。可复用的节奏是：

| 间距 | 用在哪 |
|---|---|
| 2px | 图标与文字的内部缝隙、标题与副标题 |
| 4px | 气泡内行距、资料名与 meta |
| 6px | 答案行里词与词、星级 |
| 8px | 按钮图标与文字、计数器图标与数字 |
| 10px | 词池行距、统计图标与文字、对话框按钮 |
| 12px | 卡片之间、按钮组、列表项之间、资料操作区 |
| 14px | 课程行图标与文字、任务内容与图标 |
| 16px | 页面左右、卡片内边距、按钮左右 |
| 18px | 路径节点行距、任务内边距 |
| 22–24px | 词池上下、路径上下、对话框正文 |
| 30–34px | 底部安全区、路径底部 |
| 48px | 连胜 hero 顶部 |

不要在同一个区块里同时用 12 和 14 做列间距；选一个，保持兄弟项一致。

## 8. 动效 token

| 名称 | 值 | 用途 |
|---|---|---|
| 按压 | 60ms ease | 按钮、词卡、课程行下沉 |
| 遮罩 | 200ms linear | scrim 透明度 |
| 弹层 | 280ms `cubic-bezier(.2,.9,.3,1)` | 底部 sheet 上滑 |
| 对话框 | 160ms `cubic-bezier(.2,.9,.3,1)` | 0.92 → 1 缩放 |
| Toast | 180ms ease / 180ms ease-out | 上浮 12px + 淡入 |
| 进度 | 400ms `cubic-bezier(.2,.9,.3,1)` | 填充宽度 |
| 庆祝 burst | 420ms | 0.86 → 1.05 → 1 |
| 弹入 pop | 320ms | 0.6 → 1.06 → 1，带淡入 |
| 开关 | 140ms | 背景色与滑块位移 |

`--duo-press: 60ms`、`--duo-ease: cubic-bezier(0.2, 0.9, 0.3, 1)`。详见 `references/motion.md`。

## 9. 层级

| z-index | 层 |
|---|---|
| 0 | 页面内容 |
| 80 | scrim |
| 90 | 底部 sheet |
| 100 | 对话框遮罩 + 对话框 |
| 120 | Toast |

在 `.duo-phone` 内部，scrim / sheet / dialog 都是 `position: absolute`，被手机的 `overflow: hidden` 裁切；在真实页面里它们是 `fixed`。不要混用。

## 10. 什么时候可以偏离

- **字体可以换**：有 DIN 授权就换，没有就用 Nunito；不要为了“更像”去盗用商业字体。
- **颜色不能随手换**：品牌色必须保留这七族的语义；如果产品有自己的品牌色，只替换“主行动色”这一族，并同步生成它的 100 / 500 / 600 / 700 / 800 五档。
- **尺寸可以整体放大**：桌面展示时可以把手机框放大 1.1–1.2 倍，但按钮面高、底边、描边的**比例**要保持 48:5:2。不要只放大字号。
